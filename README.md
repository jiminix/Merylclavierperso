# Meryl Clavier Perso
Clavier Android AZERTY personnalisable. Prototype V1 : couleurs, thèmes clair/sombre, touches non alphabétiques personnalisables par appui long ou dans les réglages, insertion de textes, adresses mail et URL, accès presse-papiers et Téléchargements.

## Compilation
GitHub Actions > Build APK > Run workflow ; télécharger l'artifact APK debug.

## Installation
Installer l'APK, ouvrir l'application, activer le clavier dans les paramètres Android puis le sélectionner comme méthode de saisie.

## Limites V1
Disposition inspirée d'un AZERTY Samsung, sans reproduction exacte du clavier propriétaire. Pas de prédiction, autocorrection, suggestions ni gestion avancée des accents. Le presse-papiers utilise le dernier élément autorisé par Android. Téléchargements ouvre le sélecteur de documents (ne colle pas de fichier). Les touches alphabétiques restent fixes. Les réglages restent locaux. Aucun accès réseau demandé.

## Confidentialité
Le clavier n'envoie aucune frappe à un serveur. Attention : tout clavier activé a techniquement accès au texte saisi ; n'installer que des APK de confiance.
